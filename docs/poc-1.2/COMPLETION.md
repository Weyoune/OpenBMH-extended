# Extended 1.0 Beta completion gates

The active objective is a playable, verified Extended 1.0 Beta. Work is on Extended `main`; Classic and archived 1.1 Beta releases remain independent. Existing Original rules and Classic rendering are reused. Germany/England scope and the Premier-League fallback remain as specified in `GAME_SCOPE.md`.

| Gate | Current evidence | Work still required |
| --- | --- | --- |
| World and source data | 13 league identities, 234 full-scope clubs, wide IDs, scoped data and snapshots | Final editor/package binding and full career state |
| Human management | Full initial player/manager confirmation, facilities/environment/sponsors, finance/tactics and human match state | Remaining live manager records/policy and other management actions |
| Matchday | AI/human minute calculation, dated league/cup calculations with extra time/return legs, saved account/statistics/RNG publication | Visible live ownership and full matchday services; cup/indoor/national simulation |
| Competitions | Initial national/European/domestic fields and campaigns, Source calendars, fixtures and domestic stages | Complete competition results, qualification, promotions and season transitions |
| Career services | Initial services; saved daily/weekly/monthly processing; national nomination and uncoached calendar continuation; scheduled desk loops, later-day offers, saved Toto and Core settlement | Human national preparation, remaining management UI, match/competition progression and automatic notifications |
| GUI | Original setup/manager UI, first event/desktop with manager cursor, lineup/pitch/tactics/training, country-aware league tables, stored domestic competition overview and graphical save/load via development entry; standalone data-only rules | Initial competition/receipt presentation, remaining management/menu/live adoption, table forecast/family navigation and complete later-day persistence validation |
| Delivery | Current source/data regression evidence | Three complete seasons, two/four-manager sessions, native build/UI checks, screenshots/saves and Beta package |

No gate is complete merely because its data model or a bounded Core test passes. Missing backends remain explicit until integrated, rather than manufacturing outcomes or silently using the German legacy career. Progress and validation receipts are recorded in `STATUS.md` and the private QA repository.

The country-bound [annual promotion planner](ANNUAL_PROMOTION.md) now shares
Original ordering kernels and validates completed result tables. It requires
settled licence/play-off/newcomer inputs; annual roster renewal and transactional
season publication remain open. This planning foundation does not close a gate.
