# Extended 1.0 Beta completion gates

The active objective is a playable, verified Extended 1.0 Beta. Work is on Extended `main`; Classic and archived 1.1 Beta releases remain independent. Existing Original rules and Classic rendering are reused. Germany/England scope and the Premier-League fallback remain as specified in `GAME_SCOPE.md`.

| Gate | Current evidence | Work still required |
| --- | --- | --- |
| World and source data | 13 league identities, 234 full-scope clubs, wide IDs, scoped data and snapshots | Final editor/package binding and full career state |
| Human management | Full initial player/manager confirmation, facilities/environment/sponsors, finance/tactics, owned transfer market/editor/received bids and human match state | Remaining live manager records/policy and other management actions |
| Matchday | AI/human minute calculation, dated league/cup calculations with extra time/return legs, saved account/statistics/RNG publication | Visible live ownership and full matchday services; national simulation and final indoor presentation |

| GUI | Original setup/manager UI, first event/desktop with manager cursor, lineup/pitch/tactics/training, country-aware league tables/pairings/strengths, stored domestic competition overview and graphical save/load via development entry; standalone data-only rules | Initial competition/receipt presentation, remaining management/menu/live adoption, table forecast/live pairings overlays and complete later-day persistence validation |
| Delivery | Current source/data regression evidence | Three complete seasons, two/four-manager sessions, native build/UI checks, screenshots/saves and Beta package |

No gate is complete merely because its data model or a bounded Core test passes. Missing backends remain explicit until integrated, rather than manufacturing outcomes or silently using the German legacy career. Progress and validation receipts are recorded in `STATUS.md` and the private QA repository.

The country-bound [annual promotion planner](ANNUAL_PROMOTION.md) now shares
Original ordering kernels and validates completed result tables. It requires
completed play-off inputs. Source licence/newcomer decisions and unpublished
amateur membership/loan/statistics stages are implemented with schema36 pool/tail
ownership. Annual accounts/academy/player renewal and transactional season
publication remain open. These stages do not close a completion gate.

Closing awards now have an atomic scope/revision owner with schema38 exactly-once
payment and fresh annual account/title backing. This does not complete closing
desks, accounts/academy, player renewal, qualification/archive or new-calendar
publication; no annual/three-season/Beta gate is closed by that component.

The complete per-manager Source annual account pass now has an unpublished,
qualification-bound adapter: youth settlement, bonuses, real academy donor
movement, tax choices/refunds, credit, pending sanctions and tickets retain both
RNG streams and their transcript. Missing presenters/unknown imported backing
reject atomically. English promotion now uses the actual four visible groups,
protects the lowest visible human and preserves the hidden internal division.
The annual transaction still needs player renewal, cup/calendar reset, the full
canonical title archive and final publication before any season/Beta gate closes.

Menu 28 now has a [current booked balance](BALANCE.md) in the Original screen.
Forecast/plan controls remain an explicit Beta limit pending real persistent plan
ownership. This view closes no management, annual or Beta completion gate.
