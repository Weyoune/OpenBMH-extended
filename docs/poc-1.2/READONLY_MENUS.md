# Read-only desktop views

The typed owner for Original menus 4 (achievements), 8 (calendar), 9 (indoor standings), 20 (scorers), 25 (fair play), and 26 (highscores) binds the actual canonical desk actor, saved career roster, date, controller scope, revision and generation. It preallocates each projected result before acknowledging a request. Viewing, filtering and closing preserve the complete career and both random streams. Retired requests cannot reopen a closed window. Source down-close gestures consume their trailing release before returning to the desktop.

The renderers are the existing Original screens with an explicit numeric reference and their actual supplied assets. Scorers and fair play share the Original calculators, physical member order, tie rules and limits with Native. Their explicit team list accommodates the real German and English league sizes, including the internal ten-club league when a pre-existing manager actually owns it. The current-season scorer counters remain the Original packed counters; the independent wide player archive is neither truncated nor substituted.

The calendar projects actual saved country-scoped appointments. It cannot reschedule a fixture or create a friendly. Indoor points use the actual saved selection namespace, points and previous holders with the Original sorting/display routine. Achievements require genuine manager history and its saved year origin. Country-specific compressed positions follow the producer described in `LEAGUE_HISTORY.md`; imported unknown history stays unknown.

Highscores consume the saved signature and the actual configured ledger, using the canonical owned-manager asset calculator. An unknown signature is an explicit prerequisite failure; signature zero is the known Original unranked mode. Viewing never creates, truncates or updates a highscore file.

These projections do not infer missing past records, results, tournament fields or ownership from current names. Older saves can therefore report an explicit missing prerequisite instead of displaying fabricated records. Statistics menu 23 has a separate child-page integration packet.
