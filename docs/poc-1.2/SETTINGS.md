# Settings and original EIN files

Extended owns the Original 20×9 presentation matrix as optional
`economy.presentation_options` in world schema 31. Fresh careers copy the actual
reference defaults once. Every byte, including availability and non-Boolean
values, survives world/FBM roundtrips. Older careers retain an unknown matrix;
they cannot open this menu or start the integrated match receipt by borrowing
current reference preferences.

The Original menu-19 screen, font, grid, mouse edit directions, source limits,
linked availability and right-click exit are reused with an explicit numeric
reference. `settings_request_source.hpp` supplies the same checked byte edits to
both career implementations. Manager, revision, expected 180 bytes and window
sequence are authenticated. Leaving and reopening retires the previous owner.
Headless callers without sound capabilities cannot change audio-driver cells;
the SDL entry supplies actual playback availability and applies the saved music
and click switches.

Saved preferences are installed in Core projections before desktop/match work.
They therefore drive drawer handles, drag raster, shortcut visibility,
background/text formatting and the existing match presentation consumers.
Integrated matches use the saved matrix rather than an all-one placeholder.
No settings operation advances the date, spends money or draws random numbers.

## EIN files

The original load/save controls use exactly 180 raw bytes, without FBM headers or
new encodings. Targets are regular files within the configured save directory;
overwrite requires confirmation. Saving constructs the complete replacement
view and stages the career before writing an exclusive temporary. Readback,
flush and atomic publication precede the live session/view swap. Failure keeps
the prior file and live career. Cancelling the chooser returns to its settings
window, retaining the window owner.

Import preserves original raw values and recomputes only Source availability,
retaining the raw audio-driver flags. File length is checked before reading.

## Separate owners still required

Three cells remain unavailable in this typed menu: H8 (the wall-clock desktop
deadline), Q5 and R5 (calendar admission changes). They must be connected to
those runtime owners; storing a preference alone would misrepresent their
behavior. EIN imports that change these cells are explicitly refused. The
remaining cells still obey the existing native consumer whitelist and Original
availability, rather than accepting every displayed coordinate.

The in-settings readme uses the explicit reference and the existing original
file-availability behavior. General live-match settings ownership and complete
season/release qualification remain separate work.

## Verification

Public synthetic checks cover shared write/replay guards, sound capabilities,
numeric bounds and odd speeds, schema 31 raw bytes, explicit unknown schema 30,
confined EIN paths and failed-publication preservation. Private Original-input
GUI checks cover single English and mixed English/German actors, source-grid
edits, dependent locks, desktop consumers, save/load/confirmed overwrite,
malformed and unowned-cell EIN rejection, chooser cancellation, retired windows
and unchanged full gameplay/RNG state. Platform/runtime results are recorded
with the private screenshots and matching saves; a build alone is not GUI QA.
