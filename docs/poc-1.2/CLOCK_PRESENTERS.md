# Typed clock presenters

`make_world12_clock_hooks(backdrop, active_seat)` builds the synchronous native
presenters for the typed day owner. The caller supplies the canonical last/active
desk seat explicitly. The factory does not advance a day or publish a snapshot;
the typed clock retains that authority.

The factory binds ordinary weekly auctions to the existing `0..39` selector and
outcome renderer. Its crest resolver uses each callback's `AiMatchProjection` to
map bounded seller/viewer teams to actual world crest resources. A shared
underlay retains the accepted selector frame for its subsequent outcome.
Unsolicited `40..43` offers keep their separate presenter.

Weekly incident questions display the composed Source body for the supplied
global manager. German status question kind15 obtains its body from the named
`WeeklyManagerStatusQuestion` CString when the composed body is empty. The
question still has its existing no-effect acceptance branch; missing source text
is unsupported. Current club/competition relations come from
`current_weekly_club_relations` on the staged snapshot.

Monthly contract renewal uses a staged `MonthlyRenewalModal` and the existing
Original contracts screen. Demands retain the monthly `from_desk=false` policy;
only the actual expired row receives the `screen_row` refusal flag. The shared
request validator checks manager, roster row/player, revision, request and quote.
An accepted answer requires an actual Core offer and a nonzero renewed Source
term. Explicitly closing without renewal is a refusal; interruption publishes
neither the staged contract changes nor its random stream.

Loan returns use the existing Source yes/no dialog and the authenticated special
return-offer editor, including quote/calculator controls and actual sale notices.
The editor stages both random streams and the numeric state until an explicit
Source exit. Supported editor cancellation completes the normal return; an
interrupted presenter is unsupported and leaves the transaction unpublished.
Roster A/B inspection operates on that same staged numeric workspace. Player
cards, statistics and category setters remain hidden until their staged owners
are connected.

The final clock/live/`serve_startup` hookup belongs to the native day owner. The
factory is deliberately defined before Main's handler and does not alter that
handler's calendar or live-match branches.
