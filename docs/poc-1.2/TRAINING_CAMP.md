# Original training camps

The typed career now opens the existing eight-resort training-camp screen. Map
selection, photos, quality grades, sliders, prices and feedback use the Original
assets and verified numeric rules. The renderer accepts the explicit reference
and actual crest atlas, rather than admitting dual-world data as a legacy game.

Legacy and typed sessions share `apply_training_camp_request_source`: active
manager/revision, derived fourth focus value, current focus, available funds and
the existing visit/busy limits are checked before the Core booking call. The
session stages publication and keeps a rejected request from changing its world
or random streams. Source feedback and close behaviour are retained.

Booking has immediate effects. Core calculates the fee and updates team morale,
player form/condition/technique, tactical freshness and familiarity with the W
generator. Those global players, the full tactical board, financial counters,
visit/busy byte and seed publish together; no new day or G draw is implied.

World schema **27** retains the four optional camp-focus bytes. Fresh managers
capture the real initial record. Entry normalizes the derived fourth byte using
the shared Core function without RNG. Nonzero focus survives projection and
save/load. Older unknown focus remains unknown through ordinary projections;
an older schema cannot silently discard newer focus. The new menu explicitly
requires a known record, instead of inventing historical preferences.

Synthetic checks compare shared commands with direct Core focus and booking
effects, including player words, board, morale, cash, limits and draw counts.
Private single-English and mixed-country GUI tests exercise the actual map and
slider hitboxes, booking, Source feedback, save/reload, stale/current duplicate
rejection and reopening a guarded camp. Matching screenshots and snapshots remain
private. Native morale's flag bits are separate from the canonical morale value.

This is the Classic eight-resort implementation. Modern-map designs are outside
this repository's scope. General live/calendar presenters, other management
menus and full-season delivery gates remain unfinished.
