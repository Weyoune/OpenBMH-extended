# Unpublished next-season fields and opening services

`stage_annual_fields` installs the actual completed-season qualification receipt's
next-European entrants/fields/holders, completed country titles, and real fresh
European programmes. It does not rerun year-zero selection. Domestic cup fields
use the actual post-exchange Source slots/results and pending sanctions. A
country's Super-Cup is omitted only for its known actual league/main-cup double.
Manager participation history is updated from those real fields.

Fixture order uses the shared Source position-swap kernel and Watcom stream.
Ordinary scope order retains `simulation_leagues`; retained inactive origin
leagues participate only when their actual physical records are owned. Their
rank/order changes stay in `national_origins` and do not create active fixtures.
Recruitment's old position history remains separately retained by the annual
player-lineage adapter; a new fixture order is not a new final table.

The outer owner retains completed old physical-namespace campaign receipts
before exchanges. It then uses a quiescent unpublished workspace and installs
real new indoor/regional/calendar owners after player/result reset. Saved
campaign validators are not weakened to permit mismatched old namespaces.

`stage_annual_opening_services` handles Source's days from1July to the first
Wednesday after real history/highscore/length handling. It runs direct daily
interest without stock-price updates, real human familiarity/training on its
Source weekday boundary, then the genuine new transfer-list allocation. A valid
first-Wednesday loop stops before Wednesday-to-Thursday and stays within1..7July,
so it cannot cross another weekly or monthly boundary. A completed career does
not enter this pass.

Both outputs remain unpublished. Final application ownership still includes
real National draw carry/coach work, completed title-archive append, external
highscore update order, calendar reset and closing/opening desks, published with
both random streams and one scope/revision transition. Authored component tests
are not a played calendar season or a Beta release gate.

`make_annual_calendar` reads the actual German/English appointment arrays,
clears Source runtime opening/friendly/replay cells, and aligns their verified
source weekdays to the real first Wednesday. It never fills missing dates or
manufactures matches. Both full league calendars remain validated.

`make_annual_indoor_season` retains the actual preceding Masters (or its known
previous holder when the season was suppressed), actual new reigning country
titles, and the saved Source scratch lineage. It creates an undrawn owner with
no old scores or trophies. Real scratch references outside the regular Source
namespace remain owned club IDs; first-draw workspaces retain those references.
The completed old campaign remains in the outer annual receipt. Calendar/Hall
component tests advance an authored Source programme through all30passes, then
check actual Masters/scratch carry, no-template reset, missing-owner refusal and
codec retention. They do not claim a completed calendar season.
