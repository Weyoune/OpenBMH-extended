# Persistent Original desktop actions

The typed desktop accepts its existing Source move, drawer, folder, automation
and admission-price requests. Native and typed sessions share layout validation,
formation selection and Boolean/price writes. The application still owns the
active manager, revision, idle-desktop and pending-visible-request checks.

Layout requests carry all 54 before/after records. The shared validator derives
the permitted bytes from the operation, verifies Source bounds/snap settings,
linked-list changes, folder ownership and capacity, then checks the resulting
projection. Stale layouts and changes to unrelated bytes are rejected. The typed
session stores only the active canonical seat's existing ManagerDesktop layout;
it does not replace club, player or manager identities.

The corner of an open widget removes it through the same authoritative drawer
operation as the quickbar. Its physical release barrier survives acknowledgement
and cannot activate the object underneath. Right-drag retains the Original yellow
preview and remains separate from removal. Quickbar restoration, bin-mode folder
storage and exact-child restoration use the same retained layout records.

The first automation monitor cycles only enabled saved formations, including the
manual value. The other four switches change their low bit while preserving all
other saved bits. The ticket scale retains the Original 8–25 limits. Existing
tactics/backing and career fields store those values; no new schema is needed.

Publication rebuilds and acknowledges the typed desktop before swapping the
staged session. The local toolbar/bin presentation is retained by cloning the
existing screen, rather than resetting it after every operation. Existing Source
desktop sound IDs are drained through the existing audio dispatcher on this path.
No action advances the date, draws RNG or charges cash immediately.

Synthetic checks cover high-bit preservation, formation masks, prices, actor
binding and unowned layout bytes. Private GUI input checks cover icon/widget
drags, removal/release, quickbar restore, all monitors, prices and folder/bin
restoration, with current-schema save roundtrips. A real Linux SDL drag and save
is compared with the checked snapshot plus the normal four manual-save W draws.
Screenshots and matching FBMs remain private.

[MEN layout-file import/export](MENU_LAYOUT_FILES.md) now has its own checked
file owner. Settings windows, the visible turn driver and Beta release gates
remain separate work.
