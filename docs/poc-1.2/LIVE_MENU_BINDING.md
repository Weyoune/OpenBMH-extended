# Owned live menus

The native Extended match presenter uses the existing Original live board,
scenes, lineup/pitch, tactics, family tables and settings renderers. A staged
match callback supplies the actual post-attendance career snapshot. The
accepted outer desktop is not used as a substitute for that snapshot.

`LiveSettingsScope` binds the S window to its retained match, actual human row,
shared menu generation and both random-stream positions. Cell edits use the
same Source request kernel as desk settings. Original entry-time availability,
host sound capabilities and the indoor-date refusal remain in force. The
secondary-league switch requires a separate calendar owner and is rejected by
both cell edits and EIN import. Settings export uses the ordinary checked,
atomic settings-file writer. Only the accepted presentation cells return through
the match transaction; no parked club account is imported during national play.

The live player-card facade runs the existing Core portrait/market redraw once
per actual card rebuild. Rendering itself is pure. Actual crest paths accompany
bounded drawing IDs, and the renderer accepts the prepared rules resource rather
than discovering an original executable. A running-game card cannot start a
transfer or nomination transaction. National cards use their actual nominated
squad and current national board; the Original single temporary NoTeam slot is
kept for Legacy inputs. Retained card callbacks reject after their menu retires.

National UI projectors distinguish runtime roles from numeric club indices.
Two active coaches can be displayed in local row order while commands retain
canonical career seats and the parked full career roster. Squad rows, opponent
marking candidates and fielded-player counts use the actual runtime ranges.
Rating-only nations have no invented player rows.

Initial European entrant pages use actual prepared fields, the Original eight
placement slots and actual crest assets. Only countries with a human club are
shown. The synchronous startup hook observes the unpublished prepared career;
opening a page never re-runs a draw or consumes gameplay randomness.

Validation is incremental. The private real-data minute-15 probe checks family
menus, settings cell/EIN edits, stale/replayed requests, retirement, rollback,
UI-only publication and unchanged match random streams. Native GUI checks and
complete calendar/annual playthroughs remain separate release evidence.
