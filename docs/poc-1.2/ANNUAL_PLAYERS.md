# Unpublished annual active-player renewal

`stage_annual_player_renewal` executes the shared Source annual pass on actual
active club rosters and free-pool references. It first resets every human board
and advertisement/sponsor state, including the physical loan-owner boards and
canonical presentation preferences. It then visits clubs in the actual shuffled
simulation order and the two real free pools. One global visited-ID set spans
all bounded workspaces, so a regenerated player placed in a later club/pool is
not aged a second time.

The shared ageing/retirement kernel retains real doctor recovery, insurance,
loan-owner notices, Source count quirks, regeneration and release placement.
Released IDs remain real supplied players. Loans/contracts are removed through
the actual Source release effect; live loan boards retain their Source reset
bytes and physical order. Unknown historical loan slots reject rather than
inventing an order. Historical global player/club counters remain retained.

Full free pools use the existing no-list recruitment kernel over all actual AI
clubs. Original `slot_team(slot)` is excluded before scoring, including its
foreign-skip counter and random draws. The same original-owner correction is
used by monthly overflow. Annual recruitment uses retained completed position
history: league swaps preserve a club's old rank; an amateur newcomer inherits
the old league slot's rank. Every exchange receipt and the final membership
permutation is checked. Results recomputed under a new fixture order are not a
substitute for this Source history.

The output owns the changed World, desktop/transfer state, empty new results,
zero round cursors and both random receipts. It is unpublished: date/season,
next indoor/regional/cup/calendar owners, coach/provenance refresh and the first
Wednesday/opening desk still belong to the outer annual transaction. Inactive
national provenance has a separate refresh requirement and is not silently
frozen or moved into the active market by this stage.

`begin_annual_manager_history` performs Source's fifty-season shift and next-row
marker after player renewal. The saved history-origin word is required when its
window actually shifts; a missing old origin cannot become a guessed zero.

Authored tests cover German, English and mixed club scopes; actual severe-injury
release/regeneration; live/retired loans; full hundred-player pool overflow;
strong-ID uniqueness; statistics retention; retained ranks; Source board/UI
resets; save/replay; old unknown state and stale-owner rollback. The native
presentation/ageing extraction is independently compared with complete Original
saved streams and random receipts. These are component proofs, not played-year
or complete season-publication evidence.
